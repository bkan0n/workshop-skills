# spacesForLength

`spacesForLength(length)`


Returns a string made of spaces that is the same length as the provided length (in terms of font units). The length should be the result of a calculation done by the `strVisualLength()` function.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `length` | `IntLiteral` | The length to get. Must be a literal integer, not a variable. |

Returns: `String`.
