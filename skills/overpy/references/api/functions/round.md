# round

`round(value)`


The integer that is closest to the specified value (equivalent to rounding to nearest).

To round up or down, use `ceil()` or `floor()`.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `value` | `float` | The real number to get the nearest integer of. |

Returns: `int`.
