# hsl

`hsl(hue, saturation, lightness, alpha=255)`


A custom color in HSL/HSLA format.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `hue` | `float` | The hue of the color (0-360). |
| `saturation` | `float` | The saturation of the color (0-1). |
| `lightness` | `float` | The lightness of the color (0-1). |
| `alpha` | `float` | The alpha of the color (0-255). Default: `255`. |
