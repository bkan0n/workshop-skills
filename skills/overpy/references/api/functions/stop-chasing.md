# stopChasing

`stopChasing(variable)`


Stops an in-progress chase of a variable (global or player), leaving it at its current value.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `variable` | `Variable` | Specifies which variable (global or player) to stop modifying. |

Returns: `void`.
