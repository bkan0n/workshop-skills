# receiver.remove

`<Array>.remove(value)`

Receiver: `Array`. The receiver supplies the first compiler argument.

Removes one or more Values from the Variable's array (if found). If the Variable isn't already an array, it becomes an array of one element before the remove occurs.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `value` | `Object \| Array` | The value to remove from the array (if found). If an array is given, each value is removed from the array. |

Returns: `void`.
