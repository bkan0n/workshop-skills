# random.randint

`random.randint(MIN, MAX)`

A random integer between the specified min and max, inclusive.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `MIN` | `int` | The smallest integer allowed. If a real number is provided to this input, it is rounded to the nearest integer. |
| `MAX` | `int` | The largest integer allowed. If a real number is provided to this input, it is rounded to the nearest integer. |

Returns: `int`.
