# #!extension


Activates a workshop extension. The following extensions are available:

- `beamEffects` (2 points)
- `beamSounds` (1 point)
- `buffAndDebuffSounds` (2 points)
- `buffStatusEffects` (2 points)
- `debuffStatusEffects` (2 points)
- `energyExplosionEffects` (4 points)
- `explosionSounds` (2 points)
- `kineticExplosionEffects` (4 points)
- `playMoreEffects` (1 point)
- `projectiles` (4 points)
- `spawnMoreDummyBots` (2 points)

Compile the project to obtain its extension-point usage; this catalog has no project-specific totals.
