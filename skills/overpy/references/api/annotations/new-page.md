# @NewPage

Forces the rule to be on a new page. Pages are maximum 100 rules; note that each rule costs 1 element. You can specify a string argument that will be displayed on each of the filler rules.

Source: [OverPy 9.7.17](https://github.com/Zezombye/overpy/tree/5a7d0e294b8cad73b9701987bb584d0551d7fa4d/src). Generated from pinned initialized exports.
