# @Hero

Defines which hero the current rule applies for. If omitted, defaults to all heroes. Cannot be used with `@Slot`. Not applicable for subroutines.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `hero` | `not specified` | The hero of the event. |
