# @Team

Defines which team the current rule applies for. If omitted, defaults to `all`. Not applicable for subroutines.

| Argument | Type | Meaning / default |
| --- | --- | --- |
| `team` | `not specified` | The team of the event. |

`team` choices: `1`, `2`, `all`.
