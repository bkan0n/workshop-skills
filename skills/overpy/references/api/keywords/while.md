# while

Denotes the beginning of a block that will execute in a loop as long as the specified condition is true. If the condition evaluates to false when execution is at the top of the loop, then the loop exits, and execution jumps to the next action after the end of the block.

Editor snippet template (dollar placeholders are not source syntax):

```text
while $0
```
