# in

Whether comparing the first operand with any of the elements in the second operand returns true.

For example, `3 in [1,2,3]` will return true.

Be aware that `3 in [1, true]` will return `true`, as 3 is truthy.

To check the presence of a string within another string, use `strContains`.
