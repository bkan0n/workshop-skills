`Last Text ID`

A reference to the last piece of text created by the Event Player (or created at the Global level) via the Create HUD Text, Create In-World Text, Create Progress Bar HUD Text, or Create Progress Bar In-World Text Action.

Returns: `TextId`. Types are OverPy's model of native inputs.
