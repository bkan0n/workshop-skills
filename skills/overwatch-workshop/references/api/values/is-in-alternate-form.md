# Is In Alternate Form

Native Workshop value. Signature labels below describe argument order; replace them with expressions.

`Is In Alternate Form(player)`

Whether the specified player is currently in an alternate form:

- Wrecking Ball's ball form
- Baby Dva
- Bastion's turret and tank forms
- Lucio's speed song
- Mercy's pistol
- Torbjorn's hammer

For Echo duplication, use the Is Duplicating value instead.

| Argument | Type | Meaning |
| --- | --- | --- |
| `player` | `Player` | The player whose form to check. |

Returns: `bool`. Types are OverPy's model of native inputs.
