# Press Button

Native Workshop action. Signature labels below describe argument order; replace them with expressions.

`Press Button(player, button)`

Forces one or more players to press a button virtually for a single frame.

| Argument | Type | Meaning |
| --- | --- | --- |
| `player` | `Player \| Array<Player>` | The player or players for whom the virtual button input will be forced. |
| `button` | `Button` | The button to be pressed. |

Returns: `void`. Types are OverPy's model of native inputs.
