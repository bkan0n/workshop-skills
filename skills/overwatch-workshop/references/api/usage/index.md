# Workshop functions by task

Choose the task you are implementing, read its group, then open only the relevant exact entries. Do not load every group or the whole catalog. For an already-known name, use the [alphabetical indexes](../index.md).

- [State and arrays](state-arrays.md) — Store and update variables, chase values, build or search arrays, and transform collections.
- [Timing and control](timing-control.md) — Sequence actions, wait, loop, branch, call rules or subroutines, and control reevaluation.
- [Players and bots](players-bots.md) — Choose players and heroes, manage bots and spawning, inspect player state, and control input.
- [Combat and abilities](combat-abilities.md) — Change health, damage, healing, weapons and abilities; inspect combat events, statuses, and assists.
- [Geometry and movement](geometry-movement.md) — Work with vectors, angles and raycasts; find nearby players; move, face, attach, or scale players.
- [Visuals, text and sound](visuals-text.md) — Create HUDs, effects, icons and strings; format text and colors; control cameras, visibility, and communication.
- [Match and settings](match-settings.md) — Set scores, objectives and match flow; query modes, maps and statistics; expose Workshop settings.
- [Math and randomness](math-random.md) — Calculate numbers, round values, use trigonometry, interpolate, and select or shuffle random values.
- [Debugging and performance](debugging.md) — Record diagnostic values, inspect execution, and monitor server load.
