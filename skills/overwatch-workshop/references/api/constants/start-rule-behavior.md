# StartRuleBehavior

The built-in `StartRuleBehavior` enum.


| Native English choice | OverPy symbol | Note |
| --- | --- | --- |
| `Do Nothing` | `StartRuleBehavior.NOOP` | Allow the rule to finish executing without changing its contextual values. |
| `Restart Rule` | `StartRuleBehavior.RESTART` | Restart the specified rule with new contextual values (including event player, attacker, victim, etc). |
