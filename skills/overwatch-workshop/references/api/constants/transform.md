# Transform

The built-in `Transform` enum.


| Native English choice | OverPy symbol | Note |
| --- | --- | --- |
| `Rotation` | `Transform.ROTATION` | The resulting vector will be rotated to the new frame of reference. Use this option when the provided vector is a direction or velocity. |
| `Rotation And Translation` | `Transform.ROTATION_AND_TRANSLATION` | The resulting vector will be rotated and translated to the new frame of reference. Use this option when the provided vector is a position. |
