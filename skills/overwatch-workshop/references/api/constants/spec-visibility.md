# SpecVisibility

The built-in `SpecVisibility` enum.

| --- | --- | --- |
| `Visible Always` | `SpecVisibility.ALWAYS` | Non-team spectators can always see text. |
| `Default Visibility` | `SpecVisibility.DEFAULT` | Non-team spectators can see text when all players can see it. |
| `Visible Never` | `SpecVisibility.NEVER` | Non-team spectators can never see text. |
